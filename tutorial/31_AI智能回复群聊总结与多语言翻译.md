## 1. 接口定义

| 接口 | 方法 | 路径 | 说明 |
|-----|------|------|------|
| 智能回复建议 | POST | `/ai/reply-suggestions` | 根据上下文返回 3 条候选回复 |
| 群聊总结 | POST | `/ai/group-summary` | 输出 summary/todos/decisions |
| 多语言翻译 | POST | `/ai/translate` | 自动识别源语言并翻译 |

### 1.1 请求 DTO

```go
type ReplySuggestionsRequest struct {
    TargetId     string `json:"target_id" binding:"required"`
    Style        string `json:"style"`
    Draft        string `json:"draft"`
    ContextLimit int    `json:"context_limit"`
}

type GroupSummaryRequest struct {
    GroupId string `json:"group_id" binding:"required"`
    Hours   int    `json:"hours"`
    Limit   int    `json:"limit"`
    Style   string `json:"style"`
}

type TranslateRequest struct {
    Text       string `json:"text" binding:"required"`
    SourceLang string `json:"source_lang"`
    TargetLang string `json:"target_lang" binding:"required"`
}
```

### 1.2 Service 接口

```go
type AIService interface {
    ReplySuggestions(userId string, req aireq.ReplySuggestionsRequest) (*airsp.ReplySuggestionsRespond, error)
    GroupSummary(userId string, req aireq.GroupSummaryRequest) (*airsp.GroupSummaryRespond, error)
    Translate(userId string, req aireq.TranslateRequest) (*airsp.TranslateRespond, error)
}
```

## 2. Handler 实现

AI Handler 与其他模块保持一致：

1. 从 JWT 获取 `user_id`
2. 绑定请求参数
3. 调用 Service
4. 统一 `HandleSuccess/HandleError`

```go
func (h *AIHandler) Translate(c *gin.Context) {
    userId, exists := c.Get("user_id")
    if !exists {
        HandleError(c, errorx.New(errorx.CodeUnauthorized, "请先登录"))
        return
    }

    var req aireq.TranslateRequest
    if err := c.ShouldBindJSON(&req); err != nil {
        HandleParamError(c, err)
        return
    }

    rsp, err := h.aiSvc.Translate(userId.(string), req)
    if err != nil {
        HandleError(c, err)
        return
    }
    HandleSuccess(c, rsp)
}
```

## 3. Service 实现

### 3.1 构造函数模式（与其他 Service 一致）

```go
type aiService struct {
    repos  *mysql.Repositories
    client aiclient.ChatClient
    model  string
}

func NewAIService(repos *mysql.Repositories, cfg *config.Config) *aiService {
    client, err := aiclient.NewEinoClient(cfg.ModelScopeConfig)
    if err != nil {
        zap.L().Warn("init eino client failed, ai service disabled", zap.Error(err))
    }
    return &aiService{repos: repos, client: client, model: cfg.ModelScopeConfig.Model}
}
```

### 3.2 智能回复建议实现要点

业务流程：

1. 校验 AI 客户端可用（`ensureClientReady`）
2. 校验 `target_id`、修正 `context_limit`
3. 按会话类型加载上下文（私聊/群聊）
4. 调用模型并解析 JSON
5. 返回最多 3 条建议

关键逻辑（私聊权限校验）：

```go
isFriend, err := s.repos.Friendship.IsFriend(userId, targetId)
if err != nil {
    return "", errorx.ErrServerBusy
}
if !isFriend {
    return "", errorx.New(errorx.CodeForbidden, "你们不是好友，无法获取对话上下文")
}
```

### 3.3 群聊总结实现要点

业务流程：

1. 校验 `group_id` 格式（`G` 前缀）
2. 校验调用者是否群成员
3. 拉取群消息并按时间窗口过滤
4. 让模型输出结构化 JSON（summary/todos/decisions）
5. 做兜底处理（无消息/空结果）

关键逻辑（群成员权限校验）：

```go
if _, err := s.repos.GroupMember.FindByGroupAndUser(groupId, userId); err != nil {
    if errorx.IsNotFound(err) {
        return nil, errorx.New(errorx.CodeForbidden, "你不是该群成员")
    }
    return nil, errorx.ErrServerBusy
}
```

### 3.4 多语言翻译实现要点

业务流程：

1. 校验 `text` 和 `target_lang`
2. 构造翻译 Prompt（可自动识别源语言）
3. 调用模型
4. 解析 `detected_lang` 与 `translated_text`
5. 空结果兜底报错

## 4. 模型客户端实现（Eino）

与其它基础设施模块类似，AI 模型调用统一收敛到 `internal/infrastructure/ai/eino_client.go`：

```go
chatModel, err := openai.NewChatModel(context.Background(), &openai.ChatModelConfig{
    APIKey:      cfg.ApiKey,
    BaseURL:     cfg.BaseUrl,
    Model:       cfg.Model,
    Temperature: &temperature,
    Timeout:     12 * time.Second,
})
```

统一入口：

```go
func (c *EinoClient) Generate(ctx context.Context, systemPrompt, userPrompt string) (string, error)
```

这样 Service 层只关心业务，不依赖具体模型 SDK 细节。

## 5. 路由与依赖注入

### 5.1 路由注册

```go
func (rt *Router) RegisterAIRoutes(rg *gin.RouterGroup) {
    aiGroup := rg.Group("/ai")
    {
        aiGroup.POST("/reply-suggestions", rt.handlers.AI.ReplySuggestions)
        aiGroup.POST("/group-summary", rt.handlers.AI.GroupSummary)
        aiGroup.POST("/translate", rt.handlers.AI.Translate)
    }
}
```

并在 `RegisterRoutes` 的私有路由组中注册：

```go
rt.RegisterAIRoutes(private)
```

### 5.2 Provider 注入

与现有模块一致，按三层注入：

1. `service/provider.go`：`Services` 增加 `AI AIService`
2. `handler/provider.go`：`Handlers` 增加 `AI *AIHandler`
3. `router/router.go`：注册 `RegisterAIRoutes`

## 7. 关键业务规则

- 所有 `/ai/*` 接口都走 JWT 鉴权
- 智能回复：私聊时必须好友关系；群聊时必须有会话记录
- 群聊总结：必须是群成员
- AI 异常统一返回 `ErrServerBusy`，不暴露模型细节
- AI 仅提供“建议/翻译/总结”，不自动代发消息
