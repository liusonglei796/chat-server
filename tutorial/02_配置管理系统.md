## 1. TOML 配置格式简介

TOML（Tom's Obvious, Minimal Language）是一种简洁易读的配置文件格式：

```toml
# 这是注释
[section]
key = "value"
number = 123
boolean = true
```

**优势**：
- 语法简洁，易于阅读
- 支持嵌套结构
- 有明确的类型定义

```toml
[mainConfig]
appName = "KamaChat"

accessKeyID = "your_access_key_id"

# 本地/测试环境建议：使用短信 Mock（不调用第三方短信）
# 运行前设置环境变量：KAMACHAT_SMS_MODE=mock
# 这样即使 accessKeyID/accessKeySecret 还是占位字符串，也能跑通注册/短信登录链路。

[logConfig]
logPath = "./logs"

hostPort = "127.0.0.1:9092"
loginTopic = "login"
chatTopic = "chat_message"
logoutTopic = "logout"
partition = 0
timeout = 1  # 单位秒

# 静态资源配置
[staticSrcConfig]
staticAvatarPath = "./static/avatars"
staticFilePath = "./static/files"

# JWT 配置
[jwtConfig]
secret = "kama-chat-super-secret-key-change-in-production"
accessTokenExpiry = 15      # Access Token 有效期（分钟）
refreshTokenExpiry = 168    # Refresh Token 有效期（小时），168小时 = 7天

# 雪花算法配置
[snowflakeConfig]

```

## 3. 实现配置解析

### 3.1 internal/config/config.go

```go
package config

import (
    "fmt"
    "time"

    "github.com/BurntSushi/toml"
)

// MainConfig 主配置
type MainConfig struct {
    AppName string `toml:"appName"`
    Host    string `toml:"host"`
    Port    int    `toml:"port"`
}

// MysqlConfig MySQL 配置
type MysqlConfig struct {
    Host         string `toml:"host"`
    Port         int    `toml:"port"`
    User         string `toml:"user"`
    Password     string `toml:"password"`
    DatabaseName string `toml:"databaseName"`
}

// RedisConfig Redis 配置
type RedisConfig struct {
    Host     string `toml:"host"`
    Port     int    `toml:"port"`
    Password string `toml:"password"`
    Db       int    `toml:"db"`
}

// AuthCodeConfig 验证码配置
type AuthCodeConfig struct {
    AccessKeyID     string `toml:"accessKeyID"`
    AccessKeySecret string `toml:"accessKeySecret"`
    SignName        string `toml:"signName"`
    TemplateCode    string `toml:"templateCode"`
}

// LogConfig 日志配置
type LogConfig struct {
    LogPath    string `toml:"logPath"`
    FileName   string `toml:"fileName"`   // 日志文件名
    MaxSize    int    `toml:"maxSize"`    // 单个日志文件最大大小（MB）
    MaxBackups int    `toml:"maxBackups"` // 保留旧日志文件的最大个数
    MaxAge     int    `toml:"maxAge"`     // 保留旧日志文件的最大天数
    Level      string `toml:"level"`      // 日志级别：debug, info, warn, error
}

// KafkaConfig Kafka 配置
type KafkaConfig struct {
    HostPort    string        `toml:"hostPort"`
    LoginTopic  string        `toml:"loginTopic"`
    LogoutTopic string        `toml:"logoutTopic"`
    ChatTopic   string        `toml:"chatTopic"`
    Partition   int           `toml:"partition"`
    Timeout     time.Duration `toml:"timeout"`
}

// StaticSrcConfig 静态资源配置
type StaticSrcConfig struct {
    StaticAvatarPath string `toml:"staticAvatarPath"`
    StaticFilePath   string `toml:"staticFilePath"`
}

// JWTConfig JWT 配置
type JWTConfig struct {
    Secret             string `toml:"secret"`
    AccessTokenExpiry  int    `toml:"accessTokenExpiry"`  // 分钟
    RefreshTokenExpiry int    `toml:"refreshTokenExpiry"` // 小时
}

// SnowflakeConfig 雪花算法配置
type SnowflakeConfig struct {
    MachineID int64 `toml:"machineId"` // 雪花算法节点 ID (0-1023)
}

// Config 总配置结构
type Config struct {
    MainConfig      `toml:"mainConfig"`
    MysqlConfig     `toml:"mysqlConfig"`
    RedisConfig     `toml:"redisConfig"`
    AuthCodeConfig  `toml:"authCodeConfig"`
    LogConfig       `toml:"logConfig"`
    KafkaConfig     `toml:"kafkaConfig"`
    StaticSrcConfig `toml:"staticSrcConfig"`
    JWTConfig       `toml:"jwtConfig"`
    SnowflakeConfig `toml:"snowflakeConfig"`
}

// 单例模式：全局配置实例
var config *Config

// LoadConfig 加载配置文件（支持多路径搜索）
func LoadConfig() error {
    paths := []string{
        "configs/config_local.toml",  // 优先本地配置
        "configs/config.toml",         // 默认配置
        "../../configs/config_local.toml", // 兼容从 cmd/ 目录启动
        "../../configs/config.toml",
    }

    for _, path := range paths {
        if _, err := toml.DecodeFile(path, config); err == nil {
            return nil
        }
    }

    return fmt.Errorf("could not find configuration file in any of the search paths")
}

// GetConfig 获取配置（单例）
func GetConfig() *Config {
    if config == nil {
        config = new(Config)
        _ = LoadConfig()
    }
    return config
}
```

## 4. 设计解析

### 4.1 结构体嵌入

```go
type Config struct {
    MainConfig      `toml:"mainConfig"`      // 嵌入，可直接访问 config.AppName
    MysqlConfig     `toml:"mysqlConfig"`
    // ...
}
```

使用 Go 的**结构体嵌入**特性，可以直接访问嵌入结构体的字段：

```go
cfg := config.GetConfig()
fmt.Println(cfg.AppName)      // 直接访问 MainConfig 的字段
fmt.Println(cfg.DatabaseName) // 直接访问 MysqlConfig 的字段
fmt.Println(cfg.Secret)       // 直接访问 JWTConfig 的字段
fmt.Println(cfg.MachineID)    // 直接访问 SnowflakeConfig 的字段
```

### 4.2 单例模式与配置加载

配置只需加载一次，使用单例模式确保全局唯一：

```go
var config *Config  // 包级私有变量

func GetConfig() *Config {
    if config == nil {
        config = new(Config)
        _ = LoadConfig()  // 自动搜索配置文件
    }
    return config
}
```

**多路径搜索策略**：
1. 优先加载 `config_local.toml`（本地开发配置，不提交到 Git）
2. 如果不存在，加载默认的 `config.toml`
3. 兼容从不同目录启动（项目根目录或 `cmd/` 目录）

### 4.3 TOML 标签

```go
type MainConfig struct {
    AppName string `toml:"appName"`  // 映射到 TOML 中的 appName 键
}
```

`toml` 标签用于指定 TOML 文件中的键名，实现大小写灵活映射。

### 4.4 JWT 与雪花算法配置

项目新增了两个重要配置：

**JWTConfig**：用于双 Token 认证机制
- `Secret`：JWT 签名密钥
- `AccessTokenExpiry`：短期 Access Token 有效期（分钟）
- `RefreshTokenExpiry`：长期 Refresh Token 有效期（小时）

**SnowflakeConfig**：用于分布式 ID 生成
- `MachineID`：雪花算法节点 ID（0-1023），分布式部署时每个节点必须唯一

## 6. 环境区分（可选）

### 6.1 多环境配置

创建不同环境的配置文件：

```
configs/
├── config.toml         # 生产环境配置（提交到 Git）
└── config_local.toml   # 本地开发配置（不提交到 Git，添加到 .gitignore）
```

**config_local.toml** 示例（用于本地开发）：

```toml
[mainConfig]
appName = "KamaChat-Dev"
host = "localhost"
port = 8000

[mysqlConfig]
host = "127.0.0.1"
port = 3306
user = "root"
password = "your_local_password"
databaseName = "kama_chat_dev"

[redisConfig]
host = "127.0.0.1"
port = 6379
password = ""
db = 0

[jwtConfig]
secret = "dev-secret-key-not-for-production"
accessTokenExpiry = 60       # 开发环境可设置更长的过期时间
refreshTokenExpiry = 720     # 30天

[snowflakeConfig]
machineId = 1
```

**重要提示**：
- 将 `config_local.toml` 添加到 `.gitignore`，防止敏感信息泄露
- 团队成员各自维护自己的 `config_local.toml`
- `config.toml` 作为模板提交到代码库
