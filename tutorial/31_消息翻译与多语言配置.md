# 31. 消息翻译与多语言配置

> 本教程介绍如何在 KamaChat 中接入 Eino 框架，实现“可开关 + 可自定义目标语言”的消息翻译能力。

---

## 📌 学习目标

- 理解消息翻译能力的后端分层设计
- 掌握 Eino ChatModel 的基础接入方式
- 实现翻译开关与目标语言配置
- 保持对旧客户端请求的向后兼容

---

## 1. 功能说明

本次改造后的翻译接口支持：

1. `enableTranslate`：是否启用翻译
2. `targetLang`：目标语言（如：英语、日语、法语、韩语）
3. 兼容旧请求：未传 `enableTranslate` 时默认开启翻译

当 `enableTranslate=false` 时，服务端直接返回原文，不调用大模型。

---

## 2. API 设计

### 2.1 路由

| 接口 | 方法 | 路径 | 说明 |
|-----|------|------|------|
| 翻译消息 | POST | `/messages/translate` | 对指定消息执行翻译 |

### 2.2 请求 DTO

```go
// TranslateRequest 翻译请求
type TranslateRequest struct {
    MessageID       string `json:"messageId" binding:"required"`
    EnableTranslate *bool  `json:"enableTranslate"` // nil 表示旧版本请求，默认 true
    TargetLang      string `json:"targetLang"`      // 为空时默认“英语”
}
```

### 2.3 响应 DTO

```go
// TranslateRespond 翻译响应
type TranslateRespond struct {
    TranslationEnabled bool   `json:"translationEnabled"`
    TargetLang         string `json:"targetLang"`
    OriginalText       string `json:"originalText"`
    TranslatedText     string `json:"translatedText"`
}
```

### 2.4 请求示例

```json
{
  "messageId": "M202602260001",
  "enableTranslate": true,
  "targetLang": "日语"
}
```

关闭翻译示例：

```json
{
  "messageId": "M202602260001",
  "enableTranslate": false
}
```

## 3. Eino 翻译服务实现

翻译服务使用 Eino 的 OpenAI 兼容 ChatModel，底层仍可对接 ModelScope。

```go
chatModel, err := einopenai.NewChatModel(context.Background(), &einopenai.ChatModelConfig{
    APIKey:  apiKey,
    BaseURL: baseURL,
    Model:   model,
})
```

调用翻译：

```go
resp, err := s.chatModel.Generate(ctx, []*schema.Message{
    {Role: schema.System, Content: "你是一个专业的翻译助手。"},
    {Role: schema.User, Content: "请将下面的消息翻译成日语，只返回翻译结果，不要有任何解释：\n\n你好"},
})
```

实践建议：

- 对返回结果做 `TrimSpace`，避免空白内容
- 当响应为空时返回业务错误，避免前端展示异常

---

## 4. Handler 关键逻辑

处理流程：

1. 校验登录态
2. 绑定 `TranslateRequest`
3. 根据 `messageId` 查询消息
4. 校验消息访问权限（发送者或接收者）
5. 判断是否启用翻译
6. 启用时调用翻译服务并返回结果

核心兼容策略：

```go
enableTranslate := true
if req.EnableTranslate != nil {
    enableTranslate = *req.EnableTranslate
}
```

## 6. 测试建议

### 6.1 开启翻译

- 请求：`enableTranslate=true, targetLang=法语`
- 预期：`translationEnabled=true`，`translatedText` 为法语结果

### 6.2 关闭翻译

- 请求：`enableTranslate=false`
- 预期：`translationEnabled=false`，`translatedText==originalText`

### 6.3 兼容旧客户端

- 请求：只传 `messageId`
- 预期：默认翻译为英语
