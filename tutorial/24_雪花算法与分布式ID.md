## 1. 为什么需要雪花算法?

### 1.1 传统 ID 方案对比

| 方案 | 优点 | 缺点 |
|-----|------|------|
| MySQL 自增 ID | 简单、有序 | 单点瓶颈、分库分表困难 |
| UUID | 无中心化 | 无序、36字符过长、索引效率低 |
| 雪花算法 | 有序、高性能、分布式 | 依赖时钟，需配置机器 ID |

### 1.2 雪花 ID 结构

```
|  1 bit  |     41 bit      |  10 bit  |  12 bit  |
|   符号  |     时间戳      |  机器ID  |   序列号  |
|    0    |  69年时间范围   |  1024台  |  4096/ms |
```

- **总长度**：64 bit (int64)
- **容量**：每毫秒每台机器可生成 4096 个 ID
- **有序性**：ID 按时间递增，适合数据库索引

## 4. 雪花算法封装

### 4.1 pkg/util/snowflake/snowflake.go

```go
package snowflake

import (
	"sync"

	"github.com/bwmarrin/snowflake"
	"go.uber.org/zap"

	"kama_chat_server/internal/config"
)

var (
	node     *snowflake.Node
	nodeOnce sync.Once
)

// Init 初始化雪花算法节点
func Init() {
	nodeOnce.Do(func() {
		machineID := config.GetConfig().SnowflakeConfig.MachineID
		if machineID < 0 || machineID > 1023 {
			machineID = 1
			zap.L().Warn("Invalid MachineID, using default value 1")
		}
		var err error
		node, err = snowflake.NewNode(machineID)
		if err != nil {
			zap.L().Fatal("Failed to initialize snowflake node", zap.Error(err))
		}
		zap.L().Info("Snowflake node initialized", zap.Int64("machineID", machineID))
	})
}

// GenerateID 生成雪花 ID (int64)
func GenerateID() int64 {
	if node == nil {
		Init()
	}
	return node.Generate().Int64()
}

// GenerateIDString 生成雪花 ID (string)
// 用于 JSON 序列化，避免 JavaScript 精度丢失
func GenerateIDString() string {
	if node == nil {
		Init()
	}
	return node.Generate().String()
}
```

## 6. JavaScript 精度问题

### 6.1 问题描述

JavaScript 的 `Number` 类型最大安全整数为 `2^53 - 1`：
- **最大安全值**：9007199254740991
- **雪花 ID 示例**：7452851789231923200 (超出)

### 6.2 解决方案

**后端**：JSON 序列化时将 int64 转为 string

```go
type MessageBack struct {
	Message []byte
	Uuid    int64 // 在 JSON 响应中转为 string
}

type GetMessageListRespond struct {
	Uuid    string `json:"uuid"` // 使用 string 类型
	// ...
}
```

**前端**：使用 BigInt 或字符串处理

```javascript
// 方案1：使用 BigInt
const id = BigInt("7452851789231923200");

// 方案2：保持字符串
const message = JSON.parse(response);
const messageId = message.uuid; // 字符串类型
```

## 9. 时钟回拨问题

### 9.1 问题描述

雪花算法依赖系统时钟，如果时钟回拨会导致 ID 重复。

### 9.2 解决方案

1. **NTP 同步**：使用 NTP 服务保持时钟同步
2. **检测回拨**：bwmarrin/snowflake 库会在时钟回拨时阻塞直到追上

```go
// bwmarrin/snowflake 内部实现
if now < n.time {
    // 等待时钟追上
    time.Sleep(time.Duration(n.time-now) * time.Millisecond)
}
```
